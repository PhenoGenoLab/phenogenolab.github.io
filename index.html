中南大学「医学遗传与生物信息」课题组，用生物信息、大语言模型与深度学习 构建变异解读、表型标准化与候选基因鉴定的方法与工具。这里是课题组代码的家。

代码方向

Variant

变异解读

多语种文献 → ACMG/AMP 2015 证据项，ClinVar 交叉验证，输出可追溯的证据表与评级依据。

Phenotype

表型与疾病推理

临床自由文本 → HPO 术语；HPO → 候选疾病排序（LIRICAL / CNB / BOQA 集成），MONDO 归一。

Data

数据资源

ClinVar 提交记录的证据抽取，DNA 基础模型（Enformer / Nucleotide Transformer 等）统一评测基准。

Clinical

临床落地

产前筛查 / 诊断辅助平台：文献处理流水线、RAG 后端与 Web 工作台。

开源项目

Public

LinguaSeeker

基于 ACMG/AMP 指南的变异分类辅助平台：LLM 解析多语种 PDF 文献、抽取证据、集成 ClinVar 验证，优先以 HTML 界面输出结果。

Public

demo_PhenoBrain

PhenoBrain 离线诊断流程的可复现运行环境：从 HPO 表型列表到候选疾病排序，含 Java BOQA 集成模型。
